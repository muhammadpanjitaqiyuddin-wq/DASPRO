# Dasar Pemrograman

Repository ini digunakan sebagai tempat **pengumpulan dan penyimpanan tugas mata pelajaran Dasar Pemrograman (Daspro)**.

Di dalam repository ini terdapat beberapa bagian utama, yaitu:

* **Project** — berisi project atau hasil pekerjaan pemrograman, seperti project React.
* **Tugas Teori** — berisi tugas-tugas yang berkaitan dengan materi dan teori Dasar Pemrograman.
* **Tugas Praktikum** — berisi hasil pengerjaan jobsheet atau praktikum Dasar Pemrograman.

Repository ini dibuat agar seluruh tugas dapat **tersimpan dengan rapi, terorganisir, dan mudah diakses serta diperiksa**. Repository ini juga digunakan sebagai dokumentasi hasil pembelajaran selama mengikuti mata pelajaran Dasar Pemrograman.
